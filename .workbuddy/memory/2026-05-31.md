## 每日综合资讯日报 - GitHub Actions 云端迁移

**背景**：用户反馈自动化任务经常失败，原因是每天9点时电脑不一定开着。

**解决方案**：采用方案A（GitHub Actions 云端定时任务），将日报生成和发送完全迁移到云端运行。

**已完成工作**：

1. **创建 GitHub Actions 工作流**（`.github/workflows/daily-briefing.yml`）
   - 每天北京时间 09:00 自动运行（UTC 01:00）
   - 支持手动触发测试
   - 自动上传日报为 artifact（保留30天）

2. **开发云端日报生成脚本**（`scripts/daily_briefing_cloud.py`）
   - 使用 Tavily API 搜索新闻（免费额度：1000次/月）
   - 使用 DeepSeek API 生成精选内容（¥0.1/月）
   - 支持自动识别 QQ/163/126 邮箱服务商
   - 生成五大板块各5条资讯
   - 自动生成 Markdown 和精美 HTML
   - 通过 126 邮箱 SMTP 发送邮件

3. **创建配置文件**
   - `scripts/requirements.txt`：Python 依赖包（tavily-python + openai + requests）
   - `GITHUB_ACTIONS_SETUP.md`：详细配置指南
   - `setup_github.sh`：快速设置脚本

4. **部署到 GitHub**
   - 仓库：https://github.com/hansonw5211-alt/shangy-news
   - 本地 WorkBuddy 自动化已暂停
   - GitHub Secrets 配置：TAVILY_API_KEY + AI_PROVIDER (deepseek) + DEEPSEEK_API_KEY + SENDER_EMAIL (126) + EMAIL_PASSWORD (126授权码) + RECIPIENT_EMAIL (126)
